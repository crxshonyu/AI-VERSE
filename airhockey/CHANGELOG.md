# Changelog

## 1.1.0 — 2026-11-09

GitHub 저장소에서 검토·설치·협업하기 위한 정리본입니다.

### 추가

- README 첫 화면과 빠른 실행 절차, 별도 구조·알고리즘·설치·업로드 문서.
- pyproject 기반 패키징과 `airhockey`, `airhockey-calibrate` 실행 명령.
- PC용 desktop/headless 선택 의존성과 개발 도구 버전 고정.
- Python 3.11/3.13 GitHub Actions: 정적 검사, 포맷, 테스트, 합성 실행, 빌드.
- Git 추적 제외 규칙, 이슈·PR 양식, 기여 안내.
- 설정 타입·검출 한계값·CLI 시간에 대한 회귀 테스트.

### 수정

- `"false"` 같은 문자열이 GPIO나 제어 옵션을 켤 수 없도록 JSON boolean 타입 검사.
- NaN/무한대·잘못된 HSV/핀/카메라 설정을 실행 전에 거부.
- 시리얼 상태 확인에 걸린 시간도 프레임 유효 시간과 명령 기한에 반영.
- 모터 어댑터가 전송 직전 기한을 다시 확인하고 만료된 목표는 HOLD 처리.
- 이동 중 가까운 목표로 바뀌어도 모의 모터가 속도를 순간적으로 0으로 만들지 않도록 수정.
- 보정 CLI의 기본 설정 경로를 `config/local.json`으로 통일.

실물 검증 여부는 변경되지 않았습니다. 실제 Pi·카메라·모터의 성능 측정은 별도입니다.

## 1.0.0 — 2026-11-09

- 색상 기반 퍽 검출, 픽셀/mm 보정, 속도 추정과 측면 반사 예측.
- 카메라·녹화·합성 입력, 모의/시리얼 모터 인터페이스.
- 골대 센서, RGB 상태 표시, 시간 제한 경기, CSV 기록.
- 선택적 Arduino Uno 모터 제어 예제와 기본 소프트웨어 테스트.
